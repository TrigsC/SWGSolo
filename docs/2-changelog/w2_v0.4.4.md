### As implemented (Codex-reviewed core, 4 rounds → APPROVED)

- **Real ranged combat**: `SimHunterController::engageTarget` uses
  `CombatManager::startCombat` for real mutual combat, and the equipped rifle is
  aligned as the AI's primary weapon (setPrimaryWeapon + `setupAttackMaps` after
  equip) so the AI fires it instead of falling back to unarmed.
- **Navmesh-aware hybrid movement** (hunter opt-in via
  `usesNavmeshHybridMovement()`; miners/PvP unchanged): navmesh (`getRecastPath`,
  correct node heights) inside cities, terrain-following overland in the
  wilderness, with a validated exit-boundary → off-mesh egress handoff and a
  preserved `finalDestination`. New Lua tunables
  `missionHunt.navmeshModeDebounceTicks`/`navmeshRepathTries`.
- **Polish**: per-phase announcements (de-garbled — the phase detail is spoken,
  no raw-site-key concatenation); buffs `setFillAttributesOnBuff(true)` +
  non-stacking refresh; new read-only `#/wilds` SPA route with a live
  hunter-position table (name/phase/planet/x-y/`/way`).
- The Codex loop fixed five Major route-lifecycle/TOCTOU defects and one Minor
  announcement-mapping gap (see the CR).

### Live-verification hardening (owner-verified in-game; addendum in the CR)

- **Two-way combat**: hunter bodies spawn `PLAYER | ATTACKABLE` so wildlife
  retaliates; `AiAgentImplementation::isAttackableBy` blocks real players from
  attacking a faction-0 sim bot (neutral/blue, not hover-attackable) while
  creatures still engage it.
- **Self-defense**: `SimHunterController::onTick` fights whatever is actually
  attacking (en-route interceptor, or a creature that aggros at the lair before a
  target is acquired) when no live mission target is engaged — the bot no longer
  dies passively.
- **Combat cadence**: both engage paths call `activateAiBehavior(true)` after
  `startCombat` so the weapon fires promptly (fixes multi-minute "aim but no
  shot" stalls), matching `SimPvPController`.
- **Buff + template**: enhancement buffs raised `+100` → `+2500`; body template
  moved off `artisan` (no combat skills) to the neutral `death_watch_wraith` +
  `rifle_t21`, tuned down from its DWB boss stats (HAM 120000 → 1000/1500, damage
  1020/1750 → 500/600) for hunter use.
