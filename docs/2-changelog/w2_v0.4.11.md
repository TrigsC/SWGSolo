# Changelog - Week 2, 24-07-2026, V. 0.4.11

**Release Date**: Week 2, 24-07-2026 at 12:46
**Version**: 0.4.11 (previously 0.4.6)
**Object**: F_0.4.7–F_0.4.11 cell-nav + starport ticket-collector travel: POB cell entry/egress/nearest-portal fixes, ticket-collector interplanetary travel, starport containment-margin fix, NPC pivot-swivel fixes, diagnostics behind a flag
**Code review**: `docs/3-code-review/CR_w2_v0.4.11.md` (Codex multi-round loop → APPROVED + owner-verified live addendum)

## Changes

Bundles the F_0.4.7–F_0.4.11 cell-navigation and starport-travel work (developed on
`feat/cellnav-entry-diagnostics`) plus the Phase-3 live-verification fixes. All of it is
**simulation-only** and the new travel feature is **default-off**
(`ticketCollectorTravel.enabled`).

- **POB cell entry (F_0.4.8)** — `AiAgentImplementation::findNextPosition` now adopts the
  cell on the duplicate-skip branch and null-guards the short-path fallback, so SimPlayer
  bots stop teleporting into a wall when crossing an outdoor→cell portal. Multiple real
  NPCs now traverse into building cells.

- **Cell egress (F_0.4.9)** — a cell-egress leg (`SimPlayerController::beginCellEgressIfNeeded`)
  routes a bot leaving a cell for an off-navmesh outdoor target through a portal-following
  `findPath` to a computed building-exterior point, then resumes the original hybrid/overland
  move ("pick up where it left off"). Fixes bots buffing inside a cantina then failing to
  path back out.

- **Nearest-portal egress (F_0.4.10)** — new native `BuildingObject::getNearestExteriorPortalPoint`
  (IDL, `@local`/`@dereferenced`) enumerates the exterior cell's portals and returns the
  doorway nearest the bot, fixing multi-door buildings (starports) where the single
  `getEjectionPoint()` sent the bot out the wrong side.

- **Ticket-collector interplanetary travel (F_0.4.11)** — gated `ticketCollectorTravel`:
  miners and PvP squads walk *through* the starport interior to the ticket collector in the
  enclosed hollow (departure = enter hall → cell-egress-suppressed directed route to the
  collector → board ≤ 8 m), and walk out of the destination hollow after boarding (arrival =
  re-enter a cell → egress out the front). Tri-state interior resolver
  (`resolveStarportInteriorWaypoint`), real-distance boarding gate, delayed/bounded retries,
  safe outdoor recovery, and an idempotent PvP arrival OID barrier. Seven Codex Major findings
  addressed (recovery/edge-lifecycle); happy path and disabled-legacy path preserved.

- **Starport containment-margin fix (live-verified)** — enclosed-hollow starports bake the
  collector ~10 m outside the building's collision AABB, so strict containment returned
  `NO_INTERIOR` and PvP bots wall-hugged. Two-pass selector keeps strict containment primary
  and adds a bounded horizontal margin (`interiorContainmentMarginMeters`, default 15, clamped
  0–40; next building is always 100 m+ away). **66/66 PvP collector approaches now enter the
  interior.**

- **NPC pivot-swivel fixes (live-verified "way better")** — `findNextPosition` direction calc:
  (1) hold the facing when the per-step move vector is ~0 (was applying a garbage `atan2(0,0)`
  heading); (2) normalize a negative angle with `+2*PI` instead of `+PI` (was a 180° flip),
  matching the patrol-side calc. A third cell-crossing world-space attempt was reverted
  (regressed in-cell facing — parent-relative) and logged as future work with the separate
  in-cell waypoint-feed wiggle.

- **Diagnostics behind a flag (not stripped)** — all cell-nav instrumentation
  (`CellNavDiagLog` → `bin/log/cellnav.log`: `ENGINE_*`, `STARPORT_WP_*`,
  `PVP_COLLECTOR_APPROACH`, `ENGINE_DIRECTION`, …) is retained but gated by one master flag
  (`cellNavDiag.logging`, default off); the diagnostic test-bot spawn (`cellNavDiag.enabled`)
  is likewise default off. Flip either to re-capture, no rebuild.

**Simulation safety**: no inventory/credit/market/persistence mutation; travel is `switchZone`
repositioning only; the whole travel feature is default-off and the disabled path is
byte-for-byte the legacy behavior.

**Deferred (logged in `docs/ai-cell-navigation-design.md`)**: portal-aware combat pursuit +
LoS-gated attacks (the starport-hollow combat wall-clip); the cell-crossing heading garbage;
the in-cell waypoint-feed wiggle. PvP squad behavior still pending the convergence fix.
