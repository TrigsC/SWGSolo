## Acceptance bar (owner decision)
The strict TRIP-verify profile asks for **per-member** 4/4 _contribution_ proof. Current
telemetry aggregates per squad (combat logs carry only `squadId`; `inRange`/`inCell` are
fleet-wide), so per-member contribution is not attributable. The owner explicitly accepted
this as documented debt and set the acceptance bar to **squad-level**: 4/4 _acquisition_ on a
subject patrol + squad-level real combat (controller engages + PvP kills) + convergence +
self-limiting + no idle-heal + no crash + reversibility. All of those are verified below.
